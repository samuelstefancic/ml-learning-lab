# Connect ML Learning Lab to ChatGPT

The plugin source is complete, but ChatGPT needs the MCP server to be registered as a real connection before a ChatGPT-local plugin can reference it.

## 1. Build and run

```bash
npm install
npm run build
npm start
```

The local HTTP endpoint is:

```text
http://localhost:3000/mcp
```

For remote ChatGPT testing, deploy the server to a stable HTTPS endpoint such as:

```text
https://your-domain.example/mcp
```

## 2. Register the MCP server in ChatGPT Developer Mode

1. Open ChatGPT Settings.
2. Enable Developer mode.
3. Open ChatGPT Apps / Plugins.
4. Add the deployed MCP server URL.
5. Copy the generated technical ID beginning with `plugin_asdk_app`.

## 3. Wire the registered connection into this package

Create `.app.json` at the plugin root using the technical ID generated by ChatGPT, then add this field to `.codex-plugin/plugin.json`:

```json
"apps": "./.app.json"
```

Use the exact `.app.json` shape generated for the registered connection. Do not invent a `plugin_asdk_app` ID.

## 4. Test

Open a new chat with the plugin installed and ask:

> Ouvre un exercice interactif de régression linéaire et loss.

The model should call `open_learning_lab` with `linear-regression-loss`, and the MCP App UI should render inline.
